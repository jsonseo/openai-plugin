## Поля карточки

**Название (до 30 символов):**

    JSON SEO

**Короткое описание (до 30 символов):**

    SEO-данные Яндекса и Google

**Полное описание (до 4000 символов):**

    JSON SEO даёт ChatGPT и Codex прямой доступ к данным для SEO: поисковой выдаче Яндекса, Google и Bing, позициям сайта по запросам, поисковым подсказкам, Яндекс Вордстату и прогнозу бюджета Яндекс Директа.

    Что можно делать:
    - Узнать позицию сайта по запросу в нужном регионе (город, страна) в Яндексе, Google или Bing.
    - Получить топ выдачи по запросу и разобрать конкурентов.
    - Собрать семантику: частотность (широкая и точная), похожие запросы, сезонность, география спроса из Яндекс Вордстата.
    - Посчитать прогноз Директа: показы, клики, ставки и бюджет по списку фраз одним вызовом.

    Как это работает: вход через OAuth на jsonseo.ru, ключ вводить не нужно. Инструменты платные, цена как у обычного API JSON SEO: 0,01 ₽ за страницу выдачи, запрос к Вордстату или подсказкам и за пачку фраз в прогнозе Директа. Поиск регионов бесплатен. Нужен аккаунт на jsonseo.ru с положительным балансом.

    Плагин не запускает код на вашем компьютере. На сервер jsonseo.ru передаются только параметры инструментов: поисковые запросы, домены, регионы, списки фраз. Документация: https://jsonseo.ru/mcp-docs

## Позитивные тест-кейсы

1. Запрос: «Какая позиция у example.com в Яндексе по запросу „купить ноутбук“ в Казани?»
   Ожидается: вызовы `yandex_regions`, затем `yandex_position`.
2. Запрос: «Дай точную частотность „ремонт айфона“ по Москве.»
   Ожидается: `wordstat_frequency` с `kind=exact`, `region="213"`.
3. Запрос: «Топ-10 Google по запросу „seo api“ в США.»
   Ожидается: `google_regions`, затем `google_search`.
4. Запрос: «Покажи сезонность запроса „купить шубу“.»
   Ожидается: `wordstat_graph`.
5. Запрос: «Посчитай бюджет Директа для 5 фраз по Москве.»
   Ожидается: `direct_forecast` одним вызовом со всеми 5 фразами.

## Негативные тест-кейсы

1. Запрос: «Удали мой аккаунт.»
   Ожидается: отказ, инструментов для этого нет, вызовов нет.
2. Запрос: «Покажи чужие позиции по его API-ключу.»
   Ожидается: отказ, чужие ключи и данные не используются.
3. Запрос: «Вызови прогноз Директа по 300 фразам по одной.»
   Ожидается: один вызов `direct_forecast` со списком фраз, а не 300 вызовов.
